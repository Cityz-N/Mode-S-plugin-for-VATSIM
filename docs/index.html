Mode S for VATSIM, free and simple

Pilots share their autopilot selections (altitude, heading, speed, V/S, altimeter). Controllers see them in EuroScope, coloured by whether they match the clearance.

Pilots

You need Microsoft Flight Simulator and vPilot. Nothing else.

Install

  1. Download the latest zip from the download page and unzip it.
  2. Drag the folder Community\ehslink-module into your MSFS Community folder.
    Where is my Community folder?

    MS Store: %LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalCache\Packages\Community
    Steam: %APPDATA%\Microsoft Flight Simulator\Packages\Community
    MSFS 2024 (MS Store): %LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalCache\Packages\Community (or the Community2024 folder next to it, if you use one)

    Paste the path in the Windows Explorer address bar. If you moved your packages, use the Community folder you chose at install.

  3. Drag the file vPilot\EhsLink.vPilot.dll into vPilot's Plugins folder (for example C:\vPilot\Plugins, inside the folder where vPilot is installed).
  4. Restart MSFS and vPilot. Connect as usual. vPilot's message window shows EHS Link reading … with the '…' profile. That's it.
PMDG aircraft need no extra setup. Updates for aircraft support download automatically every time you start the sim.

SimBrief: show that you're equipped (optional)

Your data reaches controllers either way. Marking your flight plan just lets them see you're equipped before your data arrives. Pick one of these:

  1. Remarks (keeps your real Mode S code): in SimBrief, type EHSLINK in the Remarks field. Your flight plan then contains RMK/EHSLINK. When filing directly on VATSIM, just add EHSLINK to the remarks.
  2. Mode S code: in your SimBrief airframe, set the Mode S code to FE5000 (any code from FE5000 to FE5FFF works). The plan then contains CODE/FE5000. F… codes belong to no real aircraft, so they can't be confused with one.

Which aircraft are supported? See the aircraft list.

Your aircraft isn't listed or looks wrong? Send a snapshot

  1. Load the aircraft, power the autopilot panel, and dial ALT 12300, HDG 123, SPD 234 (plus any V/S the aircraft allows).
  2. Wait 10 seconds. EHS Link saves a file called snapshot.txt. Nothing saved, or the aircraft won't take those values? Keep them as close as you can and set the transponder to 1230 for 10 seconds: that always saves a snapshot (do it before connecting to VATSIM).
    Where is snapshot.txt?

    MSFS 2020, MS Store: %LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalState\packages\ehslink-module\work
    MSFS 2020, Steam: %APPDATA%\Microsoft Flight Simulator\Packages\ehslink-module\work
    MSFS 2024, MS Store: %LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalState\WASM\MSFS2020\ehslink-module\work (yes, "MSFS2020")
    MSFS 2024, Steam: probably %APPDATA%\Microsoft Flight Simulator 2024\WASM\MSFS2020\ehslink-module\work
    Not there? Search your PC for snapshot.txt.

  3. Take a screenshot of the autopilot panel, then open an aircraft request and attach both. Once the profile is added, everyone gets it automatically.

Something not working?

vPilot says "the EHS Link module isn't running in MSFS"

The ehslink-module folder isn't in your Community folder, or it's nested one level too deep (it must be Community\ehslink-module\manifest.json, not Community\ehslink-module\ehslink-module\…). Restart MSFS after fixing it.

No EHS Link message at all in vPilot

EhsLink.vPilot.dll isn't in vPilot's Plugins folder, or vPilot wasn't restarted. Windows may also block downloaded files: right-click the DLL › Properties › tick Unblock › OK.

"this aircraft doesn't publish its autopilot selections…"

Your aircraft needs a profile. Send a snapshot (see above).

Controllers

You need EuroScope. Works on any network connection; nothing to open or configure.

Install

  1. Download the latest zip from the download page and unzip it.
  2. Copy EuroScope\EhsLink.dll somewhere permanent, for example your EuroScope PlugIn folder.
  3. In EuroScope: Other SET › Plug-ins › Load, pick EhsLink.dll. The chat shows EHS Link loaded.
  4. Type .ehs to check it says Connected.

Add the EHS items to your tags

In the TAG editor (or any list's column setup), choose the EHS Link items you want:

ItemShows
EHS selected altitude240 = FL240 / 24000 ft selected
EHS selected heading270, or 270T in TRK mode
EHS selected speed250 kt or M78 (--- = managed / blank)
EHS selected V/S-15 = −1500 ft/min (--- = not in V/S mode)
EHS altimeter setting1013 or 29.92
EHS current IAS / Machthe aircraft's actual speed, about every 5 s
EHS summary240 270 M78
EHS statusEHS equipped · EHS! mismatch · EHS~ draft profile · ehs filed as equipped (RMK/EHSLINK or CODE/FE5…) but no data

Prefer a list? Type .ehs list: every equipped aircraft, your clearance next to the pilot's selection.

Reading the colours

Greenexactly what you assigned
Blueclose: within 300 ft, 5°, 5 kt, M.05, 200 ft/min, 1 hPa / 0.01 inHg
Redoff, or the wrong unit (Mach selected when you gave a speed in knots)
No colouryou haven't assigned that value

Altimeter: STD is expected above your transition altitude; QNH (from the METAR of the nearer of departure and destination) below it, or once you clear the aircraft to an altitude. Make sure those airports are in your METAR list.

Examples

AFR123 B77W CFL 240 SEL 240 270 M78 EHS IAS 281 M78 DLH4AB A320 CFL 080 SEL 100 090 245 EHS! IAS 252 M42 BAW77 B789 CFL 120 SEL 120 --- --- EHS~ IAS 290 M63

Line 2: the pilot's selections, coloured against your clearance. Line 3: the aircraft's current IAS and Mach (the EHS current IAS / Mach items), plain information, never coloured, refreshed about every 5 s. The IAS/M labels are added in your tag layout; the items themselves show 281 and M78.
AFR123: cleared FL240, heading 270, M.78, and that's exactly what's set: all green.
DLH4AB: cleared to 8000 ft but 10000 is selected: red, and after 10 s an alert in the EHS Link chat tab. Speed 245 for an assigned 250 is close enough: blue. It's actually flying at 252 kt.
BAW77: data from a draft profile (EHS~, dimmer colours). Heading and speed managed (---).

In the EHS Link list

C/S CFL SEL AHDG SHDG ASPD SSPD IAS MACH ARTE SV/S QNH EHS AFR123 240 240 270 270 M78 M78 281 M78 --- --- 1013 EHS DLH4AB 080 100 090 090 250 245 252 M42 --- --- 1012 EHS! KLM62H 050 050 --- 180 --- 220 224 M36 15 -15 1018 EHS

Your clearance (CFL, AHDG, ASPD, ARTE: click to edit, as usual in EuroScope) next to the pilot's selection (SEL, SHDG, SSPD, SV/S), then current IAS/Mach and the altimeter. Columns you haven't assigned stay uncoloured.

Commands

.ehsstatus
.ehs listopen the EHS Link list
.ehs notify mine|all|offchat alerts for aircraft you track (default), all, or none
.ehs sound on|offalert sound (default off)
.ehs baro pilot|hpa|inhgaltimeter unit shown
.ehs unverified on|offshow data from draft profiles (default on)
.ehs color match|near|mismatch R,G,Bchange a colour
.ehs tol alt 300change a "close" margin (alt, hdg, spd, mach, vs, qnh, inhg)

Let pilots know you're using it

Add one line to your controller info, so pilots on your frequency know their Mode S data is being used:

XXXX_N_CTR123.450Jane ExampleC1
Monitoring 121.500
Example Radar
EHS Link enabled
Charts at charts.example.org
Time online: 00:42
EHS Link enabled

In EuroScope, the controller info is set in the connection dialog (the ATIS/controller info lines).

EHS Link is an aid. Only pilots running it send data: never use it as a basis for separation.
